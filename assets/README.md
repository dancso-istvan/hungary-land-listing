# Istenmezeje telekhirdetés – 4,99 M Ft

Frissített, magyar elsődleges GitHub Pages hirdetés.

## Fő változások
- új irányár: **4 990 000 Ft**
- egységár: **kb. 1372 Ft/m²**
- magyar nyitóoldal, rövid angol összefoglaló
- befektetői és építkezői pozicionálás
- Falusi CSOK információ óvatos, nem félrevezető megfogalmazással
- új SEO title/description/keywords
- Open Graph megosztási metaadatok
- javított robots.txt és sitemap.xml
- jobb, valódi saját fotók
- külön Marketplace/Facebook/angol szöveg

## Telepítés GitHub Pages-re
A repository jelenlegi fájljait cseréld le ennek a csomagnak a tartalmára, majd commit + push.

## Még ellenőrizendő
A nyilvános hirdetés véglegesítése előtt érdemes hivatalos dokumentumból pontosítani:
- belterület/külterület és művelési ág
- övezeti besorolás
- beépíthetőség százaléka és építménymagasság
- közművek pontos helye és csatlakozási feltételei
- hivatalos telekhatár

Ezek megadása tovább növelheti a hirdetés hitelességét és befektetői értékét.
